Jessica LifeOS

個人自動化工具 · Personal automation tool

關於 / About

Jessica LifeOS 是 Jessica Hsia 的個人自動化工具，僅供本人使用。

Jessica LifeOS is a personal automation tool built by Jessica Hsia for her own use only.

它不是商業產品，沒有註冊功能，也不開放給其他使用者。它在 Jessica 自己的電腦上執行， 把每天的天氣、行事曆、郵件與待辦整理成一份傍晚日報。

It is not a commercial product. There is no sign-up, and it is not available to anyone else. It runs on Jessica's own computer and compiles each day's weather, calendar, email, and tasks into a single evening report.

它做什麼 / What it does

  • 讀取本人的 Google Calendar，整理當天與隔天的行程
    Reads the owner's Google Calendar for today's and tomorrow's events
  • 讀取本人的 Gmail，列出未讀的重要郵件標題
    Reads the owner's Gmail to list unread important message subjects
  • 把整理好的結果寫成一頁私人筆記
    Writes the result into a single private note

隱私權 / Privacy

此工具只存取擁有者本人的帳戶資料，資料保存在本機，不分享、不販售給任何第三方。

This tool accesses only the owner's own account data. Data stays on the local machine and is never shared with or sold to any third party.
